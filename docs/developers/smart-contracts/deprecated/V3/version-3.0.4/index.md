## Documentation sources

These are the previously published 3.0.4 core contract pages, preserved without
regeneration. Periphery pages were updated at different times and retain their
individual Git Source links. This directory is a historical documentation snapshot,
not a claim that all periphery contracts share the core API version.

The previous current-docs index was changed to 3.1.0 without regenerating the core
pages. They are archived here under 3.0.4, matching the TokenizedStrategy API version
and the recorded vault source. The separately generated [3.1.0 documentation](../version-3.1.0/index.md)
uses that release's pinned core sources.

The preserved Solidity pages name their original source commits. The Vyper pages
report compiler 0.3.7; the parent repository recorded vault source commit
[104a2b2](https://github.com/yearn/yearn-vaults-v3/tree/104a2b233bc6d43ba40720d68355b04d2dc31795).
Some old source commits may no longer be available upstream. File hashes, original
source links, and recorded submodule commits are retained in `sources.json` in this
source directory.
